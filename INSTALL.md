# Установка в Codex и Claude Code

Это один переносимый каталог `lg-webos-root-privacy`, а не два расходящихся набора инструкций. Скопируйте его целиком:

| Агент | Пользовательский каталог | Вызов |
| --- | --- | --- |
| Codex | `~/.codex/skills/lg-webos-root-privacy/` (или `CODEX_HOME/skills/`) | `$lg-webos-root-privacy` |
| Claude Code | `~/.claude/skills/lg-webos-root-privacy/` | `/lg-webos-root-privacy` |

`SKILL.md` должен лежать непосредственно в этом каталоге. В Claude Code `agents/openai.yaml` не требуется; остальные инструкции/скрипты одинаковые. Если вы выбрали project scope, Claude Code также читает `.claude/skills/` в проекте. Учитывайте локальные организационные ограничения и обнаружение новых скиллов агентом. Документация Claude Code: https://code.claude.com/docs/en/skills .

Пример запроса: «Используй этот скилл: найди мой LG в домашней сети, проверь модель и firmware, подбери совместимый root и подготовь отключение рекламы и телеметрии с откатом. Универсальный пульт нужен».

Ноутбук: Python 3, доступ к сети ТВ; Git или другое средство получения проверенных исходников выбранного root-метода. ТВ для встроенных audit/policy: Python 2.7/3 и указанные в references Linux-возможности. Скилл не устанавливает зависимости, не подключается к ТВ и не запускает root при одном лишь добавлении в каталог. Он не содержит ключей/паролей, firmware-образов, upstream exploit-кода или игровых компонентов. Фактическую совместимость проверяет агент при выполнении.

Для разработки: `python scripts/self_test.py` — проверки без подключения к ТВ, mount, reboot и root. `agents/openai.yaml` — только карточка Codex, без принудительных разрешений или включения сторонних инструментов.
