# Аудит приватности

`tv_audit.py` исполняется на ТВ с Python 2.7 или 3, без сторонних библиотек. Полученный JSON содержит системные сведения, хэши кандидатов, процессы и unit states. Он не меняет настройки и не делает сетевой захват. Ошибки отмечаются в JSON. Дополнительное исследование делай только для нужной группы.

| Кандидаты из наблюдавшегося webOS 6 | Что проверить перед отключением | Возможные потери |
| --- | --- | --- |
| `acr2` | Связь с ACR/распознаванием просмотра, параметры запуска, регистрации, сетевые адреса | Live Plus, связанные рекомендации |
| `captureservice` | Потребители capture API, IPC, разрешения, пути хранения/отправки | Скриншоты, превью, зависимые приложения |
| `admanager`, `adoverlay-service` | Advertising API и callers; отличать service от WAM app | Рекламные overlays; возможные общие зависимости |
| `contentminer`, `nudge`, `livepick` | Реальное назначение на данном build, units и обращения | Рекомендации, уведомления, подбор контента |
| `rdxd`, `uploadd`, `remotelogger` | Что собирает/отправляет, кто запускает, очереди и интервалы | Диагностика и удалённые журналы |
| `iconnectivity` / QuickSet / `com.webos.service.ics` | Настройка/управление внешними устройствами и облачные запросы | Универсальный пульт, auto setup внешней техники |

Это список **кандидатов**, не доказанная универсальная классификация spyware. Не приписывай каждому компоненту скрытые скриншоты. Отмечай уровень доказательств: известное назначение, найденный вызов, реальный процесс/соединение, исследование payload. Не загружай пользовательские изображения и журналы в сторонние сервисы.

На webOS 6 встречались `homePromotion`, `screenSaverAd` в `general`, а `livePlus`, `livePromotion`, `webOSPromotionVideo`, `watchedListCollection`, `dbgLogUpload`, `faultLogUpload` — в `option`. Отдельно проверялись `eulaStatus` и рекламные согласия. На другом build ищи доступную схему, сохраняй исходные значения с их типами, используй минимальный payload и проверяй чтением. Не отзывать обязательное для выбранного приложения согласие без объяснения последствий.

Для каждой цели plan должен связывать `path + hash + unit + role + evidence + impact`. Узнай реальный exe через `/proc/PID/exe`; сопоставление подстроки в `ps` может убить не тот процесс. Обнаруженный альтернативный путь запуска требует отдельного решения. Не маскируй общий Python/node/jsserver: один runtime обслуживает много компонентов.

Сетевой слой — дополнительный: журналируй назначения для выбранных PID, различай DNS/TCP/UDP/QUIC и сравнивай до/после одинаковые действия. Блокировку DNS на ТВ/роутере добавляй только по отдельному согласованному объёму: общие LG/CDN/auth endpoints могут сломать вход, TLS-время, магазин и приложения. Не трогай общий Wi-Fi, NTP и роутер в рамках отключения рекламы на одном ТВ.
