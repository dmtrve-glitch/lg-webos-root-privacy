# LG webOS Root & Privacy Skill

[Русский](README.md) | [English](README.en.md)

Переносимый скилл для **Codex и Claude Code**: проверка совместимости root, аудит рекламы и сбора данных, обратимое отключение системных компонентов и восстановление LG webOS TV.

Это инструкция и набор инструментов для агента, работающего с вашим телевизором в локальной сети. Подходящий способ выбирается по полной модели, региону, аппаратной платформе и версиям webOS/firmware. Скилл различает получение root и замену прошивки; универсального firmware-образа или flasher в нём нет.

## Возможности

- Определение устройства, версий ПО и существующего root; проверка актуальных первичных источников.
- Сопряжение через SSAP и временный канал обслуживания после установки подходящего root-сервиса.
- Аудит ACR, capture, рекламных компонентов, рекомендаций и диагностической отправки на уровне процессов, ELF и автозапуска.
- План отключений с исходными SHA-256 и последствиями; сохранение нужных функций, включая универсальный пульт.
- Пробное применение, независимый таймер отката, сохранение после проверки и отдельная проверка первого reboot.
- Разделение наблюдений и выводов: имя процесса не считается доказательством отправки скриншотов, а краткое отсутствие соединений — доказательством отсутствия сбора.

Приложения и игровые эмуляторы в пакет не входят. Исходники сторонних root-эксплойтов загружаются и проверяются отдельно, когда агент установит их совместимость.

## Установка

Выполните команду для нужного агента. Каталог назначения должен отсутствовать. Команды с `$HOME` подходят для PowerShell и обычной Unix shell.

**Codex:**

```sh
git clone https://github.com/dmtrve-glitch/lg-webos-root-privacy.git "$HOME/.agents/skills/lg-webos-root-privacy"
```

Вызов: `$lg-webos-root-privacy`.

Это текущий пользовательский каталог из [документации Codex](https://learn.chatgpt.com/docs/build-skills). В установках, использующих прежний каталог `~/.codex/skills` или `CODEX_HOME/skills`, можно разместить скилл там; проверьте его обнаружение в своей версии. Если новый скилл не появился, перезапустите Codex.

**Claude Code:**

```sh
git clone https://github.com/dmtrve-glitch/lg-webos-root-privacy.git "$HOME/.claude/skills/lg-webos-root-privacy"
```

Вызов: `/lg-webos-root-privacy`.

Если Claude Code не подхватил новый каталог, выполните `/reload-skills` или перезапустите сеанс. Подробнее: [документация Claude Code](https://code.claude.com/docs/en/skills).

Основные инструкции: [SKILL.md](SKILL.md). Дополнительные варианты: [INSTALL.md](INSTALL.md).

Пример запроса:

> Проверь мой LG в домашней сети, установи совместимость root и подготовь отключение рекламы и телеметрии с откатом. Универсальный пульт мне нужен.

## Что находится в пакете

| Файл | Назначение |
| --- | --- |
| [scripts/tv_audit.py](scripts/tv_audit.py) | Ограниченный аудит на ТВ; ничего не отключает |
| [scripts/tv_bridge.py](scripts/tv_bridge.py) | Сопряжение, сведения о ТВ и временный exec через уже установленный Homebrew root service |
| [scripts/tv_policy.py](scripts/tv_policy.py) | Обратимая политика с trial/confirm/rollback и boot hook |
| [scripts/self_test.py](scripts/self_test.py) | Автономные проверки без живого телевизора |
| [references/](references/) | Совместимость, аудит, транспорт, восстановление и проверенный исторический кейс |
| [agents/openai.yaml](agents/openai.yaml) | Карточка скилла для Codex |

Ноутбук: Python 3 и доступ к LAN телевизора. Для встроенной системной политики на ТВ нужны Linux root, Python 2.7/3, подходящий bind mount и прочие возможности, перечисленные в [policy.md](references/policy.md). Она допускает только явно выбранные и проверенные компоненты; другие пути требуют адаптации и обзора.

## Проверка

```sh
python scripts/self_test.py
```

18 автономных проверок покрывают несовпадение hash, частичный сбой, чужие mounts, истечение guard, поздний confirm, восстановление исходных units и границы временного HTTP-сервера. Они не доказывают совместимость конкретного телевизора. Переносимые скрипты не испытывались на всех LG; [исторический кейс](references/known-case.md) описывает отдельно выполненную настройку одного webOS 6 TV.

## Источники и приватность

- [webOS Homebrew: Rooting](https://www.webosbrew.org/rooting/)
- [SlopBro upstream](https://github.com/throwaway96/slopbro)
- [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel)

В репозитории нет pairing keys, паролей, IP/serial/MAC конкретного телевизора, пользовательских журналов, backup или firmware-образов. Данные нового сеанса храните отдельно от скилла. Upstream-проекты распространяются по собственным лицензиям; SlopBro использует AGPL-3.0, его код здесь не включён.
