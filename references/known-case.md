# Проверенный кейс: границы переноса

Это локально наблюдавшийся результат, не таблица уязвимых моделей и не обещание такого же ускорения.

- LG `65UP7800PTB`, webOS `6.5.3`, firmware `03.53.45`, ARMv7.
- Root: SlopBro commit `21023d56ca424607bb03d2939609cc658c655fc7`; Homebrew Channel `0.7.3`.
- Удалось обратимо перекрыть десять ELF в `/usr/sbin/`: `acr2`, `admanager`, `adoverlay-service`, `captureservice`, `contentminer`, `nudge`, `livepick`, `rdxd`, `uploadd`, `remotelogger`.
- Связанные units: `contentminer.service`, `nudge.service`, `livepick.service`, `rdxd.service`, `uploadd.service`, `remotelogger.service`.
- После reboot: 10 из 10 целей перекрыты, целевых процессов нет, шесть units inactive; пользователь подтвердил работу изображения, пульта и Home.
- QuickSet/iconnectivity оставлен по выбору пользователя ради внешней техники.
- SSH не включали; установленный root-инсталлятором Telnet выключили. Блокировка обновлений не применялась.
- Пользователь сообщил об ускорении старта и приложений; контролируемых замеров до/после не проводилось.

Полезные особенности этого build:

1. Python на ТВ — урезанный 2.7; HTTP-сервер запускался на ноутбуке. HTTP работает в обе стороны в LAN, гостевой Wi-Fi/client isolation могут помешать.
2. `timeout` BusyBox требовал `timeout -t 25`, а не GNU-синтаксис `timeout 25`.
3. Подписка `luna-send -i` завершалась преждевременно при EOF heredoc; в `Popen` держали `stdin=PIPE` открытым до финального события. `returnValue: true` для запроса не равен финальному состоянию `installed`.
4. WAM app `com.webos.app.adoverlayex` мог выполнять привилегированный exec уже установленного Homebrew Channel. Это не универсальный app id для всех webOS.
5. SSAP close мог вернуть 403. Служебная синяя страница выглядела как неисправность ТВ, хотя Home работал. Временная страница закрывалась через `window.close()` после ответа; если не закрылась — удержание «Назад» 2–3 секунды. Сначала восстановить нормальный UI, затем подтверждать trial.
6. Отключённый `adoverlay-service` и WAM maintenance app — разные объекты. Не делать вывод об отсутствии root-канала только по сходству названий.

Пакет не включает IP, serial, MAC, pairing key, пользовательские согласия или сырые журналы того ТВ. Историческая политика того сеанса принадлежит сеансу: новый скилл не устанавливать поверх её каталога/boot hook и не считать её своими mounts.
