# Совместимость и источники

Проверяй источники заново перед каждым новым устройством. Ссылки проверены при создании 2026-10-27; это не срок гарантированной совместимости.

| Источник | Для чего использовать |
| --- | --- |
| https://www.webosbrew.org/rooting/ | Маршрутизация методов root и ограничения |
| https://www.webosbrew.org/devmode/ | Developer Mode; не путать с root |
| https://github.com/throwaway96/slopbro | Upstream SlopBro, актуальные README, issues и код |
| https://github.com/throwaway96/dejavuln-autoroot | Альтернатива для подходящих старых webOS; проверить границы версии |
| https://github.com/RootMyTV/RootMyTV.github.io | Старый RootMyTV и его ограничения; не пробовать вслепую на свежих прошивках |
| https://github.com/webosbrew/webos-homebrew-channel | Root service, persistence, поведение инсталлятора |
| https://www.lg.com/ | Поддержка конкретной модели и региона, штатные firmware и recovery |

Версия webOS и номер firmware — разные идентификаторы. Сверяй hardware/architecture, региональные suffix и исправления, а не сравнивай firmware как универсальное число для всех LG. Не меняй регион в сервисном меню ради совместимости. Не выдавай поддерживаемый год выпуска за точный ответ о конкретной прошивке.

Если есть root — не повторяй exploit. Если актуально подтверждённого пути нет, сохрани диагностику и объясни, чего не хватает. Не проверяй цепочку несовместимых exploit подряд и не переходи к downgrade без отдельного обоснования.

## Подготовка SlopBro

Выбери и зафиксируй ревизию после чтения исходников. Наш исторический commit указан в `slopbro-source-manifest.json`; это воспроизводимый пример, а не рекомендуемая навсегда версия.

```text
git clone https://github.com/throwaway96/slopbro SESSION/upstream-slopbro
git -C SESSION/upstream-slopbro checkout --detach SELECTED_COMMIT
python SESSION/upstream-slopbro/slopbro.py --help
```

До исполнения проверь diff, скачиваемые из payload зависимости, TLS, install/autoroot-последствия (постоянный root, SSH/Telnet, update settings). Проверь хэши **всех** исполняемых payload и зависимостей, не только launcher. Для новой ревизии создай собственный manifest после проверки. Manifest связывает запуск с проверенными байтами; самостоятельно вычисленный hash без доверенного источника не является подписью автора. Upstream распространяется на своей лицензии AGPL-3.0; сохраняй `COPYING` при передаче его исходников. Наш пакет их не включает.

Запускать upstream CLI из каталога сеанса с явными TV IP, local IP и webOS, если выбранная ревизия поддерживает эти параметры. Не отключать TLS ради удобства: сначала проверить дату ТВ, CA и доступность источника. Если устаревший ТВ не может проверить сертификат, рассмотреть загрузку на ноутбук с проверкой digest и локальную передачу вместо `curl -k`.

## Если пользователь действительно просит заменить firmware

Получить официальный пакет именно для полного product code/рынка; проверить подпись доступным штатным механизмом и digest, список supported models и направление версии. Пользователь должен знать, что обычный backup настроек не восстанавливает flash или bootloader. Уточнить доступный для этой платы recovery и стабильное питание. Не записывать raw flash/MTD, не подменять EPK и не делать cross-flash по похожему названию модели. При отсутствии проверенной процедуры ограничиться подготовкой и объяснить конкретное препятствие. Этот пакет не содержит универсального flasher: LG не имеет одного общего образа для всех моделей.
